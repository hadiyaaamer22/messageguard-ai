## How to Run Your Own Audit

### Lighthouse (Chrome DevTools)

1. Build: `npm run build`
2. Start: `npm start`
3. Open Chrome DevTools (F12)
4. Lighthouse tab
5. Measure page load (mobile/desktop)
6. Export results

### Bundle Analysis

```bash
npm run build
# Check .next/static/ for sizes
du -sh .next/static/chunks/
```

### Network Tab

1. DevTools → Network
2. Throttle to "Slow 4G"
3. Reload page
4. Observe load time and asset waterfall
